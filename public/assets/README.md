# PUDDING TOWER 美術素材

這裡是 MVP 實際使用的產品素材，不是原始設計分鏡。

## 來源與生成

依據已確認的角色與分享卡設計方向，以本專案原創 Canvas 路徑、焦糖填色、筆觸、陰影、果實與表情重建。未裁切原圖，不包含原圖的文字、展示框或背景。

- 角色源碼：`src/game/art/puddingArt.ts`。
- Logo／盤子／背景源碼：`src/game/art/uiArt.ts`。
- 生成工具：`scripts/export-assets.mjs`、`src/artStudio.ts`。
- 重建指令：專案根目錄 `npm.cmd run assets`。
- 機器可讀檔案列表：`manifest.json`。

共 107 張產品 PNG：40 張身體、40 張完整角色、24 張表情與 3 張 UI。角色與表情均為透明背景；完整甜點背景故意不透明。一般素材以邏輯尺寸 3 倍解析度輸出；像素風先在低解析度繪製，再以 nearest-neighbor 放大。

## 定位與使用

身體貼圖外留 28 邏輯單位透明邊界，容納帽子、草莓及描邊。身體、表情、碰撞形狀與質心偏移分開定義；碰撞不依賴 PNG 透明區域，不隨擠壓動畫縮放。複合形狀使用多個凸部件，避免在凹空區產生虛構承重面。

完整角色 PNG 的預設表情為呆萌；遊戲使用獨立表情層組合六種表情，無須人工繪製 240 張排列組合。分享卡以相同繪製源碼，依每顆 Snapshot 的形狀、風格、表情、角度與質心偏移重建。

PNG 不包含外部字型檔。Logo 由系統可用字型及原創布丁插畫產生。音效由 Web Audio 合成，沒有外部音訊素材或服務依賴。原始概念圖仍僅位於設計包，不會打包進正式遊戲。
